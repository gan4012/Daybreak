# 分镜 · 抖音竖屏

**比例** 9:16（1080×1920）　**时长** 约 50 秒　**形式** 纯录屏 + AI 配音，不出镜

**剪辑软件** 剪映专业版。新建项目先设 9:16，再把录好的横屏素材缩放填满画面。

---

## 逐镜脚本

### 镜头 1 · 钩子（0-3s）

**画面**
`E5` 素材，画面居中裁切，把「房间号」那块放大到占屏幕 1/3。
数字可以加一个轻微放大动画（剪映「缩放」关键帧，1.0 → 1.05）。

**屏幕文字**（大字，顶部）
```
不用公网IP
6位数字就能联机
```

**配音**
> 不用公网 IP，输入六位数字，就能和朋友一起玩我的世界。

**提示**：这一句要在 3 秒内说完。语速调到 1.1 倍。

---

### 镜头 2 · 痛点（3-9s）

**画面**
黑底文字卡，三行字依次弹出（剪映「打字机」入场动画）：

```
花 20 块租服务器
        ↓
折腾路由器端口映射
        ↓
或者只能同一个局域网
```

**配音**
> 以前想和朋友一起玩，要么花钱租服务器。
> 要么折腾路由器端口映射。
> 要么只能连同一个 Wi-Fi。

---

### 镜头 3 · 建房（9-17s）

**画面**
`E2`(1s) → `E3`(3s，UAC 弹窗停住让观众读) → `E4`(1s，重启) → `E5`(3s，房间号出现)

**屏幕文字**
出现在 E5 时：
```
点一下，自动生成房间号
```

**配音**
> 现在只需要点一下创建房间。
> 第一次要授权管理员权限，用于创建虚拟网卡。
> 然后就会自动生成一个六位房间号。

---

### 镜头 4 · 朋友加入（17-24s）

**画面**
`E7`(3.5s，逐字输入房间号，是重点) → `E8`(1s) → `E9`(2.5s)

**屏幕文字**
```
朋友输入同一个号
```
> 建议在 E7 画面上加一个**放大的局部截图**（输入框），否则手机屏幕上字太小看不清。

**配音**
> 朋友打开同一个启动器，输入这个房间号，就能进到同一个房间。

---

### 镜头 5 · 进服（24-32s）★ 高潮

**画面**
`F2`(1s) → `F3`(2s) → `F4`(2s) → `F5`(5s，进世界)

**屏幕文字**
```
一键进服
不用手动输地址
```

**配音**
> 然后点启动游戏并进服。
> 游戏会直接连进去，不用手动输入任何地址。

**提示**：F5 进世界那段可以配一个轻微的「叮」音效，提升爽感。

---

### 镜头 6 · 四种服务端（32-40s）

**画面**
`D2`(1s) → `D3`(5s，四种类型缓慢划过) → `D4`(2s)

**屏幕文字**
```
原版 · Fabric · Paper · Forge
四种服务端，点一下就能开
```

**配音**
> 它还能一键开服。原版、Fabric、Paper、Forge，四种服务端都支持，选好类型点一下就开始下载启动。

### 镜头 7 · 其它功能混剪（40-46s）

**画面**
`G2`(2s，搜索 JEI) → `C1`(2s) → `I1`(2s，切主题)
每个镜头 0.5 秒快速转场，配节奏感强的鼓点。

**屏幕文字**（快速闪现）
```
Modrinth 市场
版本隔离
崩溃诊断
深浅主题
```

**配音**
> 还有 Mod 市场、版本隔离、崩溃诊断、深浅主题切换。

---

### 镜头 8 · 结尾（46-52s）

**画面**
`I2` 官网下载区，缓慢滚动。最后 2 秒定格在「网盘下载」按钮上。

**屏幕文字**

```
破晓启动器
Windows 免费使用
官网 / 网盘 均可下载
```

**配音**
> 破晓启动器，Windows 免费使用，官网和网盘都能下载。

## 配音设置（剪映）

1. 选中所有配音片段 → 右键 → **文本朗读**
2. 音色选：**男声 → 解说小帅** 或 **阳光青年**（别选太机械的）
3. 语速：**1.1 倍**
4. 音调：默认
5. 全部生成后，把每段音频拖到对应时间点

> 如果觉得某个音色不好听，剪映里有十几个可选，试 3 个基本能挑到满意的。

---

## 字幕设置

1. 全选配音 → 右键 → **识别字幕**（剪映会自动根据音频生成）
2. 字幕样式：白色字 + 黑色描边，字号 8-9
3. 位置：画面下方 1/5 处，**不要太靠下**（抖音底部有按钮遮挡）

---

## 音乐

剪映 → 音频 → **音乐库** → 分类「**纯音乐 / 动感**」

推荐风格：
- 轻电子、有节奏感、不能盖过配音
- 音量调到 **15%~20%**（配音是 100%）

**避开**：带人声的歌（会和配音打架）

---

## 导出

- 分辨率：1080×1920
- 帧率：30fps
- 码率：推荐（或更高）
- 格式：MP4
