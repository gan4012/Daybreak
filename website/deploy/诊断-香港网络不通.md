## 为什么会这样

最可能的原因是 **这个 IP 被列入了某种黑名单**（可能是上一个用户留下的）。

腾讯云轻量的 IP 是回收复用的，前一个用户如果拿它做过违规的事，IP 会被打上标记，
从大陆访问就会被运营商拦掉。

**这不是你操作的问题，也不是我配置的问题。**

---

## 怎么解决：换个公网 IP

### 操作路径

**① 打开轻量应用服务器控制台**

```
https://console.cloud.tencent.com/lighthouse/instance/index
```

**② 找到 `Ubuntu-Y1LU`（150.109.66.140）这台**

**③ 点进服务器详情，找「更换公网 IP」**

通常在这些位置之一：

- 详情页 → **「更多操作」下拉菜单** → 更换公网 IP
- 或者在服务器列表 → 右侧 **「更多」** → 更换公网 IP
- 有些版本在「**概要**」标签页里直接有按钮

**④ 确认更换**

费用：**通常免费**，或者收几元。有次数限制（一般 1 个月内 1 次）。

### 换完要做的

1. **新 IP 会变**（比如变成 `150.109.xx.xx`）
2. **域名解析要改**：腾讯云 DNS → `dayberak.top` → 把 A 记录的值改成新 IP
3. **告诉我新 IP**，我立刻：
   - 测试大陆能不能访问
   - 能访问就继续配 HTTPS

## 如果换 IP 也不行

那说明**这个套餐的线路本身有问题**。备选方案：

| 方案 | 成本 | 说明 |
|---|---|---|
| **换腾讯云香港「通用型」套餐** | 差价 | 通用型的线路可能比入门型好 |
| **退掉换阿里云香港轻量** | 重新买 | 阿里云香港的回国线路评价通常更好 |
| **放弃香港，继续用国内 IP** | 0 | 官网留在 `http://101.33.201.113/`，能用只是没域名和 HTTPS |
