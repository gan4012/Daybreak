# 添加 www.dayberak.top 解析 —— 详细教程

## 先说为什么要做

现在 `dayberak.top` 已经能访问了，但 **`www.dayberak.top` 打不开**。

原因：很多人（尤其是习惯性的）会打 `www.` 开头。**没有这条记录，他们就会看到"无法访问"**，
然后以为你的网站挂了。

加一条解析，1 分钟的事。

---

## 打开 DNS 控制台

**直接点这个链接**：

```
https://console.cloud.tencent.com/cns
```

打不开就走菜单：

```
腾讯云控制台 → 搜索框输入「DNS」→ 点「DNS 解析 DNSPod」
```

**或者**左侧菜单 → 「域名与网站」→「DNS 解析 DNSPod」

---

## 找到你的域名

进去之后会看到域名列表，找 **`dayberak.top`** 这一行：

```
┌────────────────────────────────────────────────────────┐
│  域名            套餐      解析状态    到期时间           │
├────────────────────────────────────────────────────────┤
│  dayberak.top   免费版    正常        2027-xx-xx        │
└────────────────────────────────────────────────────────┘
```

**点最右边的「解析」按钮**（不是点域名名字）。

## 添加 www 记录

### ① 点左上角的蓝色按钮「添加记录」

### ② 会弹出这样的表单：

```
┌─────────────────────────────────────────────────┐
│  添加记录                                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  主机记录 *                                      │
│  ┌───────────────────────────────────────────┐  │
│  │                                           │  │
│  └───────────────────────────────────────────┘  │
│  ● 帮助：填写子域名前缀，如 www                 │
│                                                 │
│  记录类型 *                                      │
│  ┌───────────────────────────────────────────┐  │
│  │ A                                         ▾ │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  线路类型                                        │
│  ┌───────────────────────────────────────────┐  │
│  │ 默认                                      ▾ │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  记录值 *                                        │
│  ┌───────────────────────────────────────────┐  │
│  │                                           │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│  TTL                                            │
│  ┌───────────────────────────────────────────┐  │
│  │ 600                                       ▾ │  │
│  └───────────────────────────────────────────┘  │
│                                                 │
│              [ 取消 ]    [ 确定 ]                │
└─────────────────────────────────────────────────┘
```

### ③ 每个框填什么

| 框 | 填什么 | 说明 |
|---|---|---|
| **主机记录** | `www` | 只填 `www`，**不要填 `www.dayberak.top`** |
| **记录类型** | `A` | 默认就是 A，不用改 |
| **线路类型** | `默认` | 不用改 |
| **记录值** | `129.226.59.254` | 香港服务器的 IP |
| **TTL** | `600` | 默认值，不用改 |

> **最容易填错的是「主机记录」** —— 它只要前缀 `www`，
> 填成 `www.dayberak.top` 会变成 `www.dayberak.top.dayberak.top`。

### ④ 点「确定」

## 验证是否生效

### 方法一：等 1-5 分钟，然后在浏览器试

打开：

```
http://www.dayberak.top/
```

**注意**：这时候打开会显示一个「不安全」或者干脆连不上 —— **正常的**。
DNS 生效了，但**证书里还没有 www**，所以 HTTPS 会报证书错误。

### 方法二：用命令查（更准）

在电脑上打开 PowerShell（Win + X → 终端），粘贴：

```powershell
Resolve-DnsName -Name www.dayberak.top -Type A
```

**看到这样的输出就成功了**：

```
Name              Type   TTL   Section    IPAddress
----              ----   ---   -------    ---------
www.dayberak.top  A      600   Answer     129.226.59.254
```

**如果报错 `DNS name does not exist`** → 还没生效，再等几分钟。

## 生效之后告诉我，我来补证书

现在服务器上的证书**只覆盖 `dayberak.top`**，不包含 `www`。

DNS 生效后跟我说一声，我会执行：

```bash
certbot --nginx -d dayberak.top -d www.dayberak.top --expand
```

**这会把 www 加进证书**，然后：

```
https://dayberak.top/       ✅
https://www.dayberak.top/   ✅  ← 补上
http://  自动跳 https://    ✅
```

**你不需要做任何事，我远程操作就行。**

---

## 顺便说一下：`@` 和 `www` 的区别

| 主机记录 | 对应网址 | 谁会用 |
|---|---|---|
| `@` | `dayberak.top` | 你发的链接、视频里写的 |
| `www` | `www.dayberak.top` | 习惯打 www 的人（不少） |

**两个都配，谁来都不落空。**

---

## 卡住了怎么办

| 现象 | 原因 |
|---|---|
| 找不到「添加记录」按钮 | 在记录列表页左上角，蓝色按钮 |
| 提示「记录已存在」 | 那你已经加过了，看看列表里有没有 www |
| 提示「记录值格式错误」 | IP 填错了，检查是不是 `129.226.59.254` |
| 加了但还是解析不到 | 等 5-10 分钟，DNS 有缓存 |
| 打开了显示证书错误 | **正常的**，我还没补证书 |

**任何一步卡住，截图发我。**
