# 在腾讯云控制台放通 80/443 端口

> 这是给 Daybreak 官网用的操作说明。做完之后 80/443 就能从外网访问了。

## 先打开这个页面

**直接点链接**：

```
https://console.cloud.tencent.com/lighthouse/instance/index
```

如果链接打不开，就按这个路径走：

```
腾讯云控制台 → 左上角菜单 → 「轻量应用服务器」→「服务器」
```

---

## 找到你的服务器

列表里找 **IP 是 `150.109.66.140`** 的那一台。

它应该是这样一行：

```
┌──────────────────────────────────────────────────────────┐
│ [ ] Ubuntu-Y1LU     150.109.66.140    中国香港   运行中   │
└──────────────────────────────────────────────────────────┘
```

**点这台服务器的名字**（点 `Ubuntu-Y1LU` 那几个字）。

---

## 切到「防火墙」标签

进去之后，页面顶部会有一排横向的标签：

```
  概要    域名解析    云硬盘    防火墙    SSH密钥    快照    监控    文件管理
                              ↑↑↑↑↑↑
                          点这个
```

**点「防火墙」。**

---

## 找到「一键放通」按钮

进来之后，你会看到**左边一列按钮**，大概在这个位置：

```
┌────────────────────────────────────────────────────────────────┐
│  ⓘ 设置为 0.0.0.0/0 的源规则允许所有 IP 地址访问您的实例...      │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  [添加规则] [导入规则] [一键放通] [删除] [排序]      设置多台实例的防火墙? │
│                        ↑↑↑↑↑↑↑↑                                │
│                      就是这个，第三个                           │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│  应用类型              来源          协议   端口   策略   备注    │
│  Windows登录优化(…)    全部IPv4地址   UDP    3389   允许         │
│  Windows登录(3389)     全部IPv4地址   TCP    3389   允许         │
│  HTTPS (443)          全部IPv4地址   TCP    443    允许         │
│  Linux 登录 (22)       全部IPv4地址   TCP    22     允许         │
│  HTTP (80)            全部IPv4地址   TCP    80     允许         │
│  Ping                 全部IPv4地址   ICMP   ALL    允许         │
└────────────────────────────────────────────────────────────────┘
```

**「一键放通」在第二排按钮里，从左边数第三个**（添加规则、导入规则、**一键放通**、删除、排序）。

**点它。**

---

## 点完之后

会弹一个确认框，大概是「将放通常用端口，是否继续？」之类，**点「确定」**。

然后等 5~10 秒。

---

## 如果找不到「一键放通」

那可能是界面版本不同。改用**手工加规则**：

**① 点「添加规则」**（第一个按钮）

**② 填这张表**：

| 字段 | 填什么 |
|---|---|
| 应用类型 | 下拉选 `HTTP(80)` |
| 来源 | 选 `全部IPv4地址` |
| 协议 | 自动变成 `TCP` |
| 端口 | 自动变成 `80` |
| 策略 | 选 `允许` |
| 备注 | `官网` |

**③ 点「确定」**

**④ 再来一次，这次加 443**：

| 字段 | 填什么 |
|---|---|
| 应用类型 | 下拉选 `HTTPS(443)` |
| 来源 | `全部IPv4地址` |
| 策略 | `允许` |
| 备注 | `HTTPS` |

---

## 还要检查「安全组」

轻量服务器有时会**同时挂一个安全组**，它和防火墙是**两层**，两层都放行才通。

**检查路径**：

```
腾讯云控制台 → 搜索框输入「安全组」→ 点进「安全组」
```

或者左侧菜单：

```
网络与CDN → 安全组
```

**看列表里有没有安全组关联到你那台服务器**（IP `150.109.66.140`）。

- **没有** → 跳过，只管防火墙就行
- **有** → 点进去 → 找「入站规则」→ 确认有 `TCP:80` 和 `TCP:443`，来源 `0.0.0.0/0`，策略 `允许`
