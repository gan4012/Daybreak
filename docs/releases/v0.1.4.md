# Daybreak v0.1.4

> 本次更新的主题：**装起来更方便，启动按钮能看见了。**

---

## 新增：Windows 安装包

以前只有绿色包（解压 zip）。现在多了一个安装包，**双击就能装完**。

**装到哪**：`%LOCALAPPDATA%\Daybreak`（可以自己改），**全程不需要管理员权限**。

**装完有什么**：
- 开始菜单快捷方式（自动创建）
- 桌面快捷方式（默认不建，安装时可以勾）
- 卸载走 Windows 设置里的「应用」

**为什么装用户目录而不是 Program Files**：

启动器的自动更新是在「自己 exe 所在目录」原地替换文件的。装在 `Program Files` 需要管理员权限才能写，那样每次更新都会弹一次权限提示，甚至更新失败。装在用户目录就能**免权限更新**。

**卸载不会删你的数据**——配置、账号、存档都留着。

> 两种装法功能完全一样，绿色包继续提供。挑顺手的用。

## 改进：首页「启动游戏」按钮更醒目

之前首页三个按钮（刷新 / 下载 Java / 启动游戏）长得差不多，主操作不突出，有用户反馈"找不到启动按钮"。

现在：
- 按钮更大（高度 36 → 46）
- 加了播放图标
- 橙色渐变 + 外发光，一眼就能看到
- 窗口缩到最窄也不会被挤掉

顺带修了首次引导里的文案不一致（写的是「开始游戏」，按钮实际叫「启动游戏」）。

## 修正

**安装包相关**
- 安装向导改成**全中文界面**（Inno Setup 官方不带简体中文，已内置语言包）
- 安装包不包含调试符号文件（`.pdb`），体积小一点
- 打包流程里安装包生成失败不再被静默忽略

**文档**
- 修正说明书里 Java 运行时的位置：它在**游戏目录**下的 `runtime\windows-x64\<组件>\`，不在 `%APPDATA%`
- 补充了两种安装方式的对比和常见问题

**发布流程**
- 修了 CI 的产物路径（之前 zip 路径对不上，会导致发版失败）
- CI 现在会自动安装 Inno Setup 并强制要求产出安装包

## 安装

### 安装包（推荐）

下载 `Daybreak-Setup-0.1.4.exe`，双击 → 下一步 → 完成。

### 绿色包

下载 `Daybreak-beta-win-x64.zip`，解压到任意目录，双击 `Daybreak.Launcher.exe`。

> 目录里的 `easytier` 文件夹是联机组件，**不要删**。

---

## 从旧版本升级

**应用内直接更新**：设置页 → 检查更新。两种装法都支持。

老版本用户也可以下载新的安装包直接覆盖安装，**数据不会丢**（配置在 `%APPDATA%\Daybreak`，跟程序目录无关）。

## 已知问题

- **微软登录还在用开发期 ClientId**，个别情况可能受限。可在设置页填写自有的 Azure 应用 ClientId。
- **NeoForge 国内网络装不上**：官方 Maven 源连不通，Forge / Fabric 不受影响。
- **没有代码签名证书**，安装时 Windows 可能提示"已保护你的电脑"。点「更多信息」→「仍要运行」即可。
