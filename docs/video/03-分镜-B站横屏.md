## 逐镜脚本

### 开场（0:00-0:15）

**画面**
`A1` 首页，缓慢推近（剪映「缩放」关键帧 1.0 → 1.08，3 秒）

**屏幕文字**
```
破晓启动器 Daybreak
自己写的 Minecraft Java 版启动器
```

**配音**
> 这是一个自己写的 Minecraft 启动器，叫破晓启动器。
> 今天主要演示它最特别的一个能力：不用公网 IP，就能和朋友联机。

**提示**：B站开头可以直接把"最特别的能力"说出来，不用像抖音那样卖关子。

---

### 一、界面与登录（0:15-0:50）

**画面**
`A1`(2s) → `A2`(3s) → `A3`(5s，三个登录选项) → `A4`(3s)

**屏幕文字**（跟随配音出现）
```
离线 / 微软正版 / 外置登录
```

**配音**
> 界面是 WPF 加 WPF UI 做的，支持深色、浅色和跟随系统。
> 登录支持三种方式。离线登录用于单机和测试。
> 微软正版走的是 MSAL 设备码授权，令牌会自动续期。
> 外置登录支持 Yggdrasil 协议，比如 LittleSkin，会自动注入 authlib-injector，不用手动改启动参数。

---

### 二、装游戏与版本隔离（0:50-1:20）

**画面**
`B1`(2s) → `B2`(4s，滚动版本列表) → `B3`(5s，下载进度) → `C1`(3s) → `C2`(4s)

**屏幕文字**
```
自研下载引擎：分片并发 + 镜像降级
版本隔离：各版本独立存档 / 配置 / mods
```

**配音**
> 装游戏走的是自己写的下载引擎，Range 分片并发，带 SHA1 校验，官方源慢的时候会自动切到 BMCLAPI 镜像。
> 版本之间是隔离的。每个版本有自己的存档、配置和 mods 目录，只有 libraries 和 assets 共享。
> 所以换版本、装整合包，不会把原来的东西搞乱。

---

### 三、一键开服（1:20-2:10）★ 第一个重点

**画面**
`D1`(3s) → `D2`(3s) → **`D3` 四种服务端缓慢划过，每种停 1.5 秒** → `D4`(4s) → `D5`(5s，下载) → `D6`(5s，控制台输 list)

**屏幕文字**
```
Vanilla · Fabric · Paper · Forge
四种服务端，选好点一下
```

**配音**
> 它内置了四种服务端的一键安装。
> 原版、Fabric、Paper、Forge 都支持，选好版本和类型，点一下就开始下载和启动。
> 开起来之后可以直接在控制台发命令，比如 list 看在线玩家，op 给人权限。
> 停服的话用的是 stop 命令，世界会正常保存，不会因为强杀进程丢档。

**提示**：D3 这一镜**一定要慢**，观众需要看清有四个选项。可以在画面上加四个角标文字。

---

### 四、好友联机（2:10-3:20）★★★ 全片核心

**画面**
`E1`(3s) → `E2`(2s) → `E3`(4s，UAC) → `E5`(6s，房间号) → `E6`(2s)
→ `E7`(6s，输入房间号) → `E8`(2s) → `E9`(4s)
→ `F1`(3s) → `F2`(2s) → `F3`(4s) → `F4`(4s) → `F5`(10s，进世界)

**屏幕文字**（分段出现）
```
① 创建房间 → 得到 6 位房间号
② 朋友输入房间号加入
③ 点「启动游戏并进服」
```

**配音**
> 这部分是重点。
> 点创建房间，第一次会要求管理员权限，因为它需要在你的电脑上创建一块虚拟网卡。授权之后重启一次。
> 然后会生成一个六位的随机房间号。
> 朋友在同一个启动器里输入这个号码，就能进到同一个虚拟网络。
> 这里用的是 P2P 组网，会优先尝试直接打洞。如果两边网络打不通，才会走中继节点中转。
> 所以跨网络也能连，不需要你有公网 IP，也不需要配路由器。
> 最后点启动游戏并进服，游戏会直接带上服务器地址启动，不用在游戏里手动输 IP。

**提示**：
- E5 的房间号出现时，**加一个局部放大框**圈住房号
- F5 进世界那段可以稍微放慢到 0.8 倍速，让观众看清确实进去了
- 如果只有一台电脑录，E7 那段用画中画或文字卡标注"朋友那边"

### 五、Mod 生态与诊断（3:20-3:50）

**画面**
`G1`(2s) → `G2`(5s，搜 JEI) → `G3`(3s) → `H1`(2s) → `H2`(4s) → `I1`(4s，切主题)

**屏幕文字**
```
Modrinth 市场 · 整合包导入（免 Key）
崩溃诊断：12 条规则
```

**配音**
> Mod 这块接了 Modrinth 市场，能按游戏版本和加载器筛选，搜到就能装。
> 整合包支持 mrpack 和 CurseForge 的 zip，CurseForge 那边是不需要 API Key 的。
> 游戏崩了的话，它会扫 crash-reports 和 latest.log，用十二条规则翻译成具体建议，不用自己对着堆栈猜。

**屏幕文字**

Windows 10 / 11 64 位
官网 / Gitee / 网盘 均可下载

## 配音设置

1. 建议用**男声 · 解说**类音色
2. 语速 **1.0 倍**（B站观众不赶时间，正常语速更舒服）
3. 每段配音之间留 0.3-0.5 秒空白，别太密

---

## 字幕

- 用剪映「识别字幕」自动生成后**逐句核对**
- 技术名词容易识别错，重点检查：`Yggdrasil`、`authlib-injector`、`BMCLAPI`、`Modrinth`、`Forge`
- 字幕放在画面下方，字号 7-8

---

## 音乐

- **开场和结尾**有音乐，中间讲解部分**音乐压到 8%~10%** 或直接静音
- B站观众更在意内容，音乐太响反而扣分
