## 二、两条路，挑一条

### 路线 A：在粗剪上精修（推荐，快）

1. 剪映 → 新建项目 → 比例选 **16:9**（或 9:16）
2. **导入** `粗剪/rough-16x9.mp4`，拖到时间轴
3. **导入** `配音输出-快/字幕.srt` → 文本 → 智能字幕 → 导入字幕
4. 现在你有一条完整的片子了，接着做精修：
   - 加背景音乐（音量压到 15%~20%）
   - 在某几段加转场
   - 调整某段的停留时间（切开删掉多余部分）
   - 加片头片尾

**优点**：10 分钟就能出一条能发的片子。

### 路线 B：从原始素材重新摆（可控性高，慢）

1. 新建项目，比例 16:9
2. 把 `clips/` 里的片段按下面的**分镜顺序表**逐个拖上去
3. 导入 `配音.mp3` 和 `字幕.srt`
4. 对着配音节奏调每段的长度

**优点**：每段素材都是完整的，你想怎么裁都行。

## 五、剪映操作要点

### 导入素材
- **音频** → 导入 → `配音.mp3` → 拖到时间轴，左端对齐 0 秒
- **文本** → 智能字幕 → 导入字幕 → `字幕.srt`
  > 字幕已经带 BOM，剪映能正确识别中文，不会乱码

### 字幕样式
- 白色字 + 黑色描边，字号 8~9
- **位置放在画面下方 1/6 处**：抖音底部有按钮遮挡，别太靠下
- 竖屏版画面只占上半部分，字幕正好放空白处

### 背景音乐
- 剪映 → 音频 → 音乐库 → 搜「轻电子/动感」
- 音量 **15%~20%**（配音是 100%，别让音乐盖过配音）
- 避开带人声的歌

### 导出
| | 抖音 | B站 |
|---|---|---|
| 分辨率 | 1080×1920 | 1920×1080 |
| 帧率 | 30fps | 30fps |
| 码率 | 推荐或更高 | 8000~10000 kbps |

## 六、已知问题（录制时留下的）

**1. `D4-填信息` 的服务端类型没选中**

WPF-UI 的自定义 ComboBox 在自动化点击下选不中（UIA 的 SelectionItem 模式它也不响应）。
画面里名称填好了，但类型下拉是空的。

- **影响**：只有这一段。第 11 句用的是 `D3-服务端类型`，不受影响。
- **顺带提醒**：这可能是**真实的可访问性 bug**（键盘/辅助工具用户也可能选不中），
  建议你手工点一下验证：打开新建服务端 → 点类型下拉 → 点一个选项，看能不能选中。

**2. 没有"进到游戏世界"的镜头**

需要真开一个服务端 + 启动游戏，你选择跳过了。所以第 10 句用的是房间号画面。
逻辑上说得通（"点进服就会直接连进去"），但少了一个最有说服力的证据。
如果以后补录，放在第 10 句位置替换即可。

**3. 没有"朋友输入房间号加入"的镜头**

需要第二台设备。第 8 句用的是 `E6-房间信息`。可以用文字卡补一句"朋友那边输入 374623"。

**4. 提权后的窗口我操作不了**

UAC 之后启动器变成管理员进程，普通权限的自动化（UIA + 模拟点击）会被 UIPI 挡住，
所以 `E5`、`E6` 这两段是**你点的、我录的**。这是 Windows 的安全机制，不是 bug。

## 七、怎么改文案重出配音

```powershell
# 1. 改 docs/video/script-抖音.txt（一行一句）
# 2. 重新生成配音和字幕
powershell -File docs/video/tools/tts.ps1 -ScriptFile docs/video/script-抖音.txt -Rate "+20%"
# 3. 重新拼粗剪
& "C:\Users\32109\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" docs\video\tools\assemble.py
```
