# 演示视频制作包

纯录屏 + AI 配音，不出镜。目标是抖音（竖屏短）和 B站（横屏长）各一条。

## 文件说明

| 文件 | 什么时候看 |
|---|---|
| `01-录制清单.md` | **先看这个**，按清单把素材录出来 |
| `02-分镜-抖音竖屏.md` | 剪抖音版时对照 |
| `03-分镜-B站横屏.md` | 剪 B站版时对照 |
| `04-标题文案.md` | 发布时直接复制 |

## 整体流程

```
① 按「录制清单」录素材        约 25 分钟
       ↓
② 剪映里按分镜拼接           约 30 分钟（抖音）
       ↓
③ 加智能字幕 + AI 配音       约 20 分钟
       ↓
④ 导出竖屏版 → 再做横屏版     约 30 分钟
       ↓
⑤ 用「标题文案」发布
```

## 核心卖点（所有内容都围绕这个）

**不用公网 IP，输入 6 位数字就能和朋友联机玩 Minecraft。**

这是竞品没有的能力。市面上同类启动器能开服，但做不到"零配置跨网络联机"。

次要卖点：
- 四种服务端一键开服（原版 / Fabric / Paper / Forge）
- 三合一登录（离线 / 微软正版 / 外置登录）
- 一键进服，不用手动输地址

## 工具

| 用途 | 工具 | 说明 |
|---|---|---|
| 录屏 | OBS Studio（推荐）或 剪映自带录屏 | OBS 免费，能指定录制区域 |
| 剪辑 | **剪映专业版（PC）** | 免费，智能字幕和 AI 配音都在这里 |
| 配音 | 剪映「文本朗读」 | 选"男声-解说"类音色，语速调到 1.1 倍 |
| 记录 | 本文件夹的清单 | 录的时候勾选，别漏镜头 |

## 录制参数（重要）

| 项目 | 设置 | 原因 |
|---|---|---|
| 分辨率 | 1920×1080 | 两个平台都够用，竖屏版本后续裁切 |
| 帧率 | 30 fps | 软件操作不需要 60，文件更小 |
| 格式 | MP4 / H.264 | 剪映直接能吃 |
| 录制区域 | **只录启动器窗口**（1280×820） | 别录整个桌面，会带出你的桌面图标和聊天软件 |
| 鼠标 | 移动放慢，点击前停顿 0.3 秒 | 观众需要时间看清你点了什么 |

## 三个必须注意的坑

**① 关掉通知和隐私信息**

- Windows：设置 → 系统 → 通知 → 关闭
- 退出微信/QQ/钉钉
- 桌面不要有带真实姓名的文件
- 启动器里玩家名改成 `Steve` 之类的通用名，别用真名

**② 录制前先跑一遍**

启动器第一次运行可能弹入门引导、首次下载 Java。这些**不要录进视频**，提前跑完。

**③ 窗口不要盖住桌面**

启动器放在屏幕左上角，周围留空白，避免录到桌面壁纸上的私人内容。
