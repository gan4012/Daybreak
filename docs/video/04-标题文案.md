```

1. 四种服务端（原版 / Fabric / Paper / Forge）一键开服

· 161 项单元测试，开源在 GitHub

# 通用发布建议

## 发布时间

| 平台 | 建议时段 |
|---|---|
| 抖音 | 中午 12:00-13:00 或 晚上 19:00-22:00 |
| B站 | 晚上 19:00-22:00（周末更好） |

## 评论区置顶（两个平台都发）

```
下载：
官网 http://101.33.201.113/
Gitee 也发了，网盘链接在简介里

## 发布后要做的

1. **前 2 小时盯着评论区** —— 这个时段互动决定推荐量
2. 有人问"怎么下载"就回复一遍链接
3. 有人报 bug 就记下来，攒到下一个版本修
4. **别删差评**，认真回复比删更有用

## 避坑

- ❌ 别在标题里写"最强""最好用"—— 会被判定标题党，也招黑
- ❌ 别写"替代 PCL2"—— 容易被对线，而且你也没这个定位
- ❌ 别刷量 —— 抖音/B站都有检测，轻则限流重则封号
- ✅ 主动说"内测版""有 bug 欢迎反馈" —— 降低预期，反而好评多

# 两个平台文案的核心差异

| | 抖音文案 | B站文案 |
|---|---|---|
| 长度 | 短，3-4 行 | 可以长，写清实现细节 |
| 重点 | 结果（能联机） | 过程（怎么做的） |
| 语气 | 直接、有冲击 | 平实、技术向 |
| 技术细节 | 一句不提 | 主动讲 |
| 引导 | 强（"👇下载"） | 弱（"欢迎提 Issue"） |
