# Daybreak 安装包与首页启动按钮 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给启动器增加一个「双击就能装、装完有快捷方式」的安装包，并把首页的「启动游戏」按钮做成一眼能看见的主操作。

**Architecture:** 用 Inno Setup 6 生成安装包，**装到 `%LOCALAPPDATA%\Daybreak`（用户目录，不需要管理员）**——这是关键决策：现有自更新器是在「自己 exe 所在目录」里原地替换文件的，装到用户可写目录后，自更新链路一行代码都不用改。绿色包（zip）继续保留，两条分发通道并存。

**Tech Stack:** Inno Setup 6（已装在 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`）、PowerShell 5.1、WPF / XAML、xUnit。

**Spec:** 本文件即设计文档。背景决策见对话记录：用户 2026-10-27 询问「推不推荐打包安装程序」，结论是先做「启动按钮强化」+「安装包」，ClientId 转正与微软商店上架不在本次范围。

## Global Constraints

- **仅 Windows**，x64。目标系统 Windows 10 1809+。
- **只允许同步启动器本体**：`src/ tools/ scripts/ docs/ third_party/ .github/` 与根目录文件。`website/`、`video/`、`dist/` 不入库。
- **禁止把 IP / 密码 / 密钥写进任何文件**。需要地址时写占位符。提交前 `scripts/check-secrets.ps1 -Staged` 必须通过（pre-commit 钩子已装）。
- **含中文的 `.ps1` 必须 UTF-8 带 BOM + CRLF 行尾**（PS 5.1 要求）。改完用 `ParseFile` 解析无错 + 前 3 字节为 `EF BB BF` 校验。
- **构建前必须杀进程**：`Get-Process Daybreak.Launcher | Stop-Process -Force`。
- **改 UI 必须实机截图验证**（`tools/capture-safe.ps1`），不能只看编译通过。
- 版本号唯一来源是根目录 `Directory.Build.props` 的 `<Version>`，安装包脚本必须读它，不许另写一份。
- 安装包**不得需要管理员权限**：`PrivilegesRequired=lowest`，默认目录 `{localappdata}\Daybreak`。

## Review Focus

1. **安装目录可写性** —— 装在 `%LOCALAPPDATA%` 时自更新器能否无 UAC 完成覆盖并重启；若有人手滑改成 `Program Files`，更新会静默失败。
2. **快捷方式指向的有效性** —— 应用自更新替换 exe 后，桌面/开始菜单快捷方式仍指向同一路径且能启动；卸载后不留死链。
3. **首页按钮在窄窗口下的表现** —— 窗口缩到最小宽度时，「启动游戏」按钮不能被挤掉或文字换行。
4. **绿色包与安装包并存** —— 两种形态各自独立可用，互不覆盖用户数据（`%APPDATA%\Daybreak`）。
5. **安装包内的联机组件完整性** —— `easytier/` 六个文件（含 `relay.txt`）必须进安装包，否则装完联机不可用。

### Task 2: Inno Setup 安装包

**Files:**
- Create: `scripts/daybreak.iss`
- Create: `scripts/package-installer.ps1`
- Modify: `scripts/package.ps1`（在末尾追加调用，不改现有逻辑）

**Interfaces:**

- Produces: `dist/Daybreak-Setup-<version>.exe`

- [ ] **Step 1: 写 `scripts/daybreak.iss`**

关键指令（版本号由脚本 `/D` 传入，不写死）：

```ini
#define AppName "Daybreak"
#define AppNameCN "破晓启动器"
#define AppVersion GetFileVersion(AddBackslash(SourcePath) + "..\publish-beta\Daybreak.Launcher.exe")

[Setup]
AppId={{8F3A2C41-5B7E-4D92-A1C6-3E9B7D4F2A85}
AppName={#AppNameCN}
AppVersion={#AppVersion}
DefaultDirName={localappdata}\Daybreak
DisableDirPage=no
PrivilegesRequired=lowest
ArchitecturesAllowed=x64compatible
ArchitecturesInstallIn64BitMode=x64compatible
OutputDir=..\dist
OutputBaseFilename=Daybreak-Setup-{#AppVersion}
Compression=lzma2/max
SolidCompression=yes
WizardStyle=modern
UninstallDisplayName={#AppNameCN}
SetupIconFile=..\src\Daybreak.Launcher\daybreak.ico

[Tasks]
Name: "desktopicon"; Description: "创建桌面快捷方式"; GroupDescription: "附加任务:"
Name: "startmenu";   Description: "创建开始菜单快捷方式"; GroupDescription: "附加任务:"; Flags: checkedonce

[Files]
Source: "..\publish-beta\*"; DestDir: "{app}"; Flags: ignoreversion recursesubdirs createallsubdirs

[Icons]
Name: "{userdesktop}\{#AppNameCN}"; Filename: "{app}\Daybreak.Launcher.exe"; Tasks: desktopicon
Name: "{userprograms}\{#AppNameCN}"; Filename: "{app}\Daybreak.Launcher.exe"; Tasks: startmenu

[Run]
Filename: "{app}\Daybreak.Launcher.exe"; Description: "立即启动"; Flags: nowait postinstall skipifsilent

[UninstallDelete]
; 只删安装目录；%APPDATA% 的配置与游戏数据一律保留
Type: filesandordirs; Name: "{app}"
```

**必须注意的三点：**
1. `PrivilegesRequired=lowest` + `{localappdata}\Daybreak` —— 保证自更新不需要管理员
2. `AppId` 用固定 GUID，**不要每次生成新的**，否则升级会装出两份
3. `[UninstallDelete]` **只删 `{app}`**，绝不能碰 `%APPDATA%\Daybreak` 或游戏目录

- [ ] **Step 2: 写 `scripts/package-installer.ps1`**

要求：
- 读 `Directory.Build.props` 取版本号（用 `ReadAllText` + 正则，**不要用 `[xml](Get-Content -Raw)`**——PS 5.1 会把 UTF-8 当 ANSI 读成乱码，这个坑踩过）

- 检查 `publish-beta/easytier/relay.txt` 存在（缺了联机不可用）
- 定位 `ISCC.exe`：先查 PATH，再查 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`
- 调用 `ISCC.exe /DMyAppVersion=<版本> scripts\daybreak.iss`
- 输出 `dist/Daybreak-Setup-<版本>.exe` 并打印大小 + SHA256

参数：`-SkipBuild`（不重新打包，直接用现有 `publish-beta/`）

- [ ] **Step 3: 在 `package.ps1` 末尾追加安装包生成**

在现有「同步发行目录」之后加一段：若找到 ISCC 就调用 `package-installer.ps1 -SkipBuild`，找不到只打印一行提示，**不报错**（不能让没装 Inno Setup 的人打不出 zip）。

Run: `powershell -File scripts/package-installer.ps1`

## 明确不在本次范围

| 事项 | 原因 |
|---|---|
| **微软 Azure ClientId 转正** | 代码侧已完成（`LauncherConfig.MicrosoftClientId` + 设置页可填）。剩下的是你去 Azure 注册应用，把 ID 填进去，**不是代码任务** |
| 代码签名证书 | 要花钱买。没证书时安装包照样会弹 SmartScreen，做与不做区别不大 |
| 上架微软商店 | 用户量没到 |
| 自动更新安装包本身 | 绕过：安装版靠应用内自更新，不需要重下安装包 |
| 卸载时清理 `%APPDATA%` | **故意不做**——用户攒的配置和存档不该被卸载程序删掉 |
