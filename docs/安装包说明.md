# 安装方式说明

破晓启动器有两种装法，**功能完全一样**，按自己的习惯选一个就行。

---

## 两种方式对比

| | 安装包 | 绿色包（zip） |
|---|---|---|
| 适合谁 | 不想管文件放哪儿的 | 喜欢自己掌控目录的 |
| 操作 | 双击 → 下一步 → 完成 | 解压 → 双击 exe |
| 需要管理员权限 | **不需要** | 不需要 |
| 快捷方式 | 自动建（开始菜单） | 无，自己拖 |
| 卸载 | 控制面板直接卸 | 删文件夹 |
| 更新 | 应用内一键更新 | 应用内一键更新 |

**两种都支持应用内自动更新**，装的哪种都不影响。

---

## 方式一：安装包（推荐给大多数人）

### 装

1. 双击 `Daybreak-Setup-<版本>.exe`
2. 一路「下一步」
3. 安装位置默认是：

   ```
   %LOCALAPPDATA%\Daybreak
   ```

   也就是 `C:\Users\你的用户名\AppData\Local\Daybreak`

   **想换地方可以点「浏览」自己选。**

4. 「附加任务」页面：
   - ☑ 开始菜单快捷方式（默认勾选）
   - ☐ 桌面快捷方式（默认不勾，想要就自己勾上）
5. 装完可以直接勾「立即启动」

**全程不会弹管理员权限提示。**

### 卸

Windows 设置 → 应用 → 找到「破晓启动器」→ 卸载。

或者在开始菜单里右键图标 → 更多 → 打开文件位置，里面有个 `unins000.exe`。

---

## 方式二：绿色包

### 装

1. 把 zip 解压到**任意目录**，比如 `D:\Games\Daybreak`
2. 双击 `Daybreak.Launcher.exe`
3. 想要快捷方式就自己发一个到桌面

**这个目录里的 `easytier` 文件夹不能删** —— 那是联机组件，删了就用不了联机。

### 卸

直接删掉整个文件夹就行。

---

## 你的数据存在哪

**卸载不会删这些，重新装回来数据还在。**

| 内容 | 位置 |
|---|---|
| 账号、设置、日志 | `%APPDATA%\Daybreak` |
| 游戏本体、存档、Mod | 你设置的 `.minecraft` 目录 |
| 服务端实例（含世界存档） | `<游戏目录>\daybreak-servers\` |

`%APPDATA%\Daybreak` 里具体有什么：

```
config.json      启动器设置
accounts.json    账号
logs\            运行日志（反馈问题时要带上这个）
runtime\         自动下载的 Java 运行时
```

> **注意**：卸载只删程序，不删数据。想彻底清干净得自己手动删上面三处——
> 这么设计是故意的，卸载程序手滑删了存档就找不回来了。

## 自动更新怎么工作

设置页有个「检查更新」按钮，检测到新版本会：

```
提示有新版 → 你确认 → 下载 → 校验 → 覆盖 → 自动重启
```

**安装包和绿色包的行为完全一致。**

安装包之所以选用户目录（`%LOCALAPPDATA%`）而不是 `Program Files`，就是为了这个——
`Program Files` 需要管理员权限才能写，那样每次更新都要弹一次权限提示。

## 常见问题

**Q: 装了安装版，又解压了一个绿色包，会冲突吗？**

不会。两者独立，都读同一份 `%APPDATA%\Daybreak` 配置，游戏目录也是同一个。
只是会有两份程序文件，建议只留一份。

**Q: 安装包会弹"Windows 已保护你的电脑"吗？**

可能会。这是因为安装包**没有买代码签名证书**，跟安装包本身无关——
绿色包同样会弹 SmartScreen。点「更多信息」→「仍要运行」即可。

**Q: 之前用绿色包，现在想换成安装版**

直接装，然后把旧的绿色包文件夹删掉。数据不会丢（在 `%APPDATA%` 里，跟程序目录无关）。

**Q: 更新失败怎么办？**

下载最新的安装包重装一遍即可，数据不会丢。

**Q: 装到 D 盘可以吗？**

可以。安装向导里点「浏览」自己选。只要那个目录**你有写权限**就行——
放 `C:\Program Files` 会有更新问题，别放那儿。
